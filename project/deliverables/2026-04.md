## 2026-04 status
Initial April 2026 progress for capability router v1.

2026-04 update (DONE)
Implemented April Chunk 1 router foundations:
- Added a deterministic router scoring model over:
  - latency
  - cost
  - quality
  - compliance
- Added a simple deterministic constraint satisfaction pass before scoring:
  - `maxLatencyMs`
  - `maxCostPer1KTokens`
  - `minQualityScore`
  - `requiredComplianceTags`
- Added stable tie-breaking that does not depend on candidate list order:
  - score descending
  - compliance descending
  - quality descending
  - latency ascending
  - cost ascending
  - provider/model/version lexical order
- Added config-driven router candidates and weights in `appsettings.json`
- Added `POST /router/decide` so the routing decision can be exercised through the API
- Added test coverage for:
  - highest-score selection
  - deterministic constraint filtering
  - order-independent deterministic output
  - stable tie-breaking
  - no-match behavior with explicit rejections
- Test suite now passes with 44 total tests.
