2026-05 update (DONE)
Completed the final router v2 metrics-weighting slice:
- Added runtime-only metrics weighting to router scoring.
- Metrics are blended deterministically into latency/quality scoring after hard constraint filtering.
- Missing metrics, disabled metrics, zero blend weight, or zero metric sample count fall back to the static candidate score.
- Replay remains stable because replay uses the recorded routing decision from the signed manifest instead of live router configuration or metrics.
- Extended benchmark reporting with:
  - metrics enabled/disabled state
  - metrics blend weight
  - metrics count
  - selected score
  - optional static-vs-metrics comparison via `--compare-without-metrics`
- Added tests for:
  - metrics-weighted routing changing the selected candidate
  - disabled metrics preserving static routing
  - benchmark CLI static-vs-metrics comparison output
- Updated NuGet packages while keeping dependency versions stable and `net10.0`-compatible.
- Kept `Microsoft.AspNetCore.OpenApi` pinned to `10.0.2`; `11.x` preview packages target the .NET 11 API surface and broke the `net10.0` build.
- Reverted preview/dev dependency updates (`Microsoft.Extensions.Options` 11 preview, `Serilog.Settings.Configuration` dev build, `xunit.runner.visualstudio` preview) to stable versions.
- Test suite now passes with 60 total tests.
